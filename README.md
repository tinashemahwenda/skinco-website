# Skin.Co Website

A modern, responsive website for Skin.Co, a skin aesthetics company located in Harare.

## Features

- Responsive design
- Modern UI with Tailwind CSS
- Mobile-friendly navigation
- Consultation booking form
- Product showcase
- Customer testimonials

## Tech Stack

- HTML5
- Tailwind CSS
- JavaScript (Vanilla)

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Development

The project uses Tailwind CSS for styling. The main stylesheet is in `src/input.css` and gets compiled to `dist/output.css`. Run `npm run dev` to watch for changes and recompile the CSS automatically.
